# Bioinformatics & Phylogenomics Workflows

This repository contains computational workflows, Bash scripts, and Python scripts developed and/or used during my PhD research in plant molecular systematics, phylogenomics, population genomics, and historical biogeography.

## Research areas

- ddRAD-seq data processing and SNP/variant analysis
- VCF and BCF file processing
- Population genetic analysis using ADMIXTURE
- Plastome assembly using NOVOPlasty and GetOrganelle
- Phylogenomic data processing
- Historical biogeographic analysis using BioGeoBEARS
- Sequence data processing and quality control
- Reproducible command-line bioinformatics workflows

## Tools and languages

### Programming and scripting
- Bash
- Python

### Bioinformatics
- NOVOPlasty
- GetOrganelle
- ADMIXTURE
- BioGeoBEARS
- bcftools
- samtools
- VCF/BCF processing

## About

These workflows were developed/used as part of my doctoral research on the taxonomy, phylogeny, phylogenomics, and historical biogeography of Smilax L.
